# ORIGIN LAB

ORIGIN LAB is a private local research and design-assistance tool for print-on-demand T-shirt ideas.

It is designed for personal use and helps analyze public marketplace information such as active listings, prices, listing age, favorites, and public shop indicators.

ORIGIN LAB does not place orders, access private buyer or seller data, edit Etsy listings, or automatically publish products.

The tool also helps create original design directions and prepare artwork for print-on-demand production.
